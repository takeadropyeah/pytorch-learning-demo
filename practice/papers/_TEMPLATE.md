### 摘要里要警惕的三件事

- [ ] **数字的条件**：是单模型还是集成？是 test set 还是 val？
- [ ] **比较的基线**：和谁比？公平吗（参数量、计算量同一量级）？
- [ ] **作者的措辞**："easier to optimize" 和 "higher accuracy" 是两件事

### 必看的图

- [ ] Figure 1 是什么？它想证明什么？
- [ ] 论文的主图（通常是 Fig 1 或 Fig 2）画了什么？

## 第二遍（30 分钟）· 论证链条

| 步骤 | 论文里的位置 / 一句话 |
|---|---|
| ① 观察现象 | |
| ② 排除其他解释 | |
| ③ 理论推导 | |
| ④ 定位病因 | |
| ⑤ 提出方法 | |
| ⑥ 验证方法 | |
| ⑦ 消融实验 | |

**缺了哪一步？** 缺的步骤就是这篇论文最容易被攻击的地方。
