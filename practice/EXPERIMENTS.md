# 实验记录

每次训练完记一行。**这是你唯一能积累经验的地方**——模型会忘，参数会忘，记录不会。

规则：
- 一次实验一行，跑崩的实验也记（记下崩的现象，同样是知识）
- 「结论」只写一句，但要具体：不要写"效果更好"，写"加了增强后测试集 +3.2%，训练集降了"
- 对比实验要连着编号，方便回头看
- **等价性验证（重构、换写法但结果不该变）也要记**，它证明你的改动没引入回归

## 基线指纹（先看这个）

`practice\01_baseline.py` 的"标准答案"。**任何改动之后先跑一次，和这里逐位对照：**

```
数据集：y = sin(x) + data_weight*x + noise_std*ε，x ∈ [-3, 3]，N = 2000
train_loss = 0.00313982
val_loss   = 0.14961701
（8 位小数，必须逐位一致）
```

改配置或重构代码后这两个数变了，**先停下来查**——要么你改了逻辑，要么引入了新的随机性。别带着问题往下写。

| P2 | **CutMix 或 MixUp** | 改训练循环（不是一行 transform）：在 batch 内混合图像和标签 | 约 60 分钟 | 实验 #13 卡在 94.13%，剩下 0.87 点要靠更**强**的增强。CutMix 是 CIFAR 上公认最有效的一档（通常 +1~1.5），而且是"混合样本"思路的代表，和 RandomErasing（遮挡）本质不同 |
| P3 | **Label smoothing** | `CrossEntropyLoss(label_smoothing=0.1)`，一行 | 约 60 分钟 | 最便宜的一个：让标签从硬 0/1 变软，抑制过度自信。通常 +0.3~0.5，可以和 P2 叠加 |

**跑之前必须做的一件事**（已设置，但换机器/重装系统后要重设）：

```powershell
powercfg /change standby-timeout-ac 0     # 插电时永不睡眠
```

因为 Windows 判定"空闲"看的是键鼠操作，不看 GPU 是否在忙。默认 10 分钟就睡，人一离开训练就断。

**长训练的正确姿势**（实验 #13 已验证）：

```powershell
python .\05_resnet_train.py --epochs 100 --tag p1_100ep 2>&1 |
    Tee-Object -FilePath ..\logs\p1_100ep.log
```

断了用同一条命令加 `--resume` 接着跑。
